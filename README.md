# Bank Management System - OOP 🏦

A C++ console-based application that simulates a banking system. This project was developed to apply core Object-Oriented Programming (OOP) concepts in a real-world scenario.

## 🚀 Features
* **Account Management:** Support for different account types like Savings Account and Current Account.
* **Transactions:** Handle user transactions securely and efficiently.
* **Customer Management:** Link accounts to specific customer profiles.

## 🛠️ OOP Concepts Applied
This project demonstrates the practical use of:
* **Encapsulation:** Protecting account balances and customer data using access modifiers.
* **Inheritance:** Extending a base `Account` class to create specialized `SavingsAccount` and `CurrentAccount` classes.
* **Polymorphism:** Method overriding for different account behaviors.
* **Abstraction:** Hiding complex implementation details of the banking operations from the user.

## 💻 Technologies Used
* **Language:** C++
* **Structure:** Separated header (`.h`) and source (`.cpp`) files for clean architecture.
